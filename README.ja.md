## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
|---------|-------------|
| 🔄 **データクリーニング** | 生のアンケートデータを整理し、構造化されたデータセットへ変換。 |
| 📊 **ピボットテーブル** | 参加者の行動を効率的に集計・分析するためのピボットテーブルを作成。 |
| 🎛️ **インタラクティブスライサー** | 国別およびスマートフォン利用カテゴリ別にデータをフィルタリング。 |
| 📈 **ダッシュボード** | 視覚的な分析を可能にするインタラクティブなExcelダッシュボードを構築。 |
| 😴 **睡眠分析** | 参加者の睡眠品質の分布を評価。 |
| 📱 **スマートフォン利用分析** | スマートフォン依存、就寝前の利用、ナイトモード使用状況を分析。 |
| 🌍 **国別インサイト** | 複数の国の参加者行動を比較分析。 |
| 💡 **ビジネスインサイト** | 調査データから研究や意思決定に役立つ実用的な洞察を抽出。 |

## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis.git
````

### 2️⃣ プロジェクトへ移動

```bash
cd sleep-smartphone-analysis
```

### 3️⃣ Excelファイルを開く

以下のファイルを開きます：

```
Sleep&SmartphoneAnalysis.xlsx
```

**Microsoft Excel 2016以降**で開いてください。
