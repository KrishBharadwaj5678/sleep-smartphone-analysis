## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|---------|-------------|
| 🔄 **Очистка данных** | Организация и преобразование исходных данных опроса в структурированный набор данных. |
| 📊 **Сводные таблицы** | Создание сводных таблиц для эффективного анализа поведения участников. |
| 🎛️ **Интерактивные срезы** | Фильтрация данных по странам и категориям использования смартфонов. |
| 📈 **Дашборд** | Создание интерактивной панели Excel для визуального анализа. |
| 😴 **Анализ сна** | Оценка распределения качества сна среди участников. |
| 📱 **Использование смартфона** | Анализ зависимости от телефона, использования перед сном и применения ночного режима. |
| 🌍 **Анализ по странам** | Сравнение поведения участников из разных стран. |
| 💡 **Бизнес-инсайты** | Получение практических выводов из данных опроса для исследований и принятия решений. |

## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis.git
````

### 2️⃣ Перейдите в папку проекта

```bash
cd sleep-smartphone-analysis
```

### 3️⃣ Откройте Excel-файл

Откройте файл:

```
Sleep&SmartphoneAnalysis.xlsx
```

с помощью **Microsoft Excel 2016 или более поздней версии**.
