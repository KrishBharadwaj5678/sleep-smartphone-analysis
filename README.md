<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/sleep%26smartphone.jpg" width="40"/> Sleep & Smartphone Usage Analysis</h1>

## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature | Description |
|---------|-------------|
| 🔄 **Data Cleaning** | Organized and transformed raw survey data into a structured dataset. |
| 📊 **Pivot Tables** | Created Pivot Tables to summarize participant behavior efficiently. |
| 🎛️ **Interactive Slicers** | Enabled filtering by country and smartphone usage category. |
| 📈 **Dashboard** | Built an interactive Excel dashboard for visual analysis. |
| 😴 **Sleep Analysis** | Evaluated sleep quality distribution among participants. |
| 📱 **Smartphone Usage** | Analyzed doomscrolling, phone usage before bed, and night mode adoption. |
| 🌍 **Country Insights** | Compared participant behavior across multiple countries. |
| 💡 **Business Insights** | Derived actionable insights from survey data for research and decision making. |

## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

```bash
git clone https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis.git
```

### 2️⃣ Navigate to the Project

```bash
cd sleep-smartphone-analysis
```

### 3️⃣ Open the Excel File
