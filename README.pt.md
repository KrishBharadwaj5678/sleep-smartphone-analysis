<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/sleep%26smartphone.jpg" width="40"/> Análise de Sono e Uso de Smartphone</h1>

<p align="center">

## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
|---------|-------------|
| 🔄 **Limpeza de Dados** | Organização e transformação dos dados brutos da pesquisa em um conjunto de dados estruturado. |
| 📊 **Tabelas Dinâmicas** | Criação de tabelas dinâmicas para resumir o comportamento dos participantes de forma eficiente. |
| 🎛️ **Segmentações Interativas** | Permite filtrar dados por país e categoria de uso do smartphone. |
| 📈 **Dashboard** | Construção de um dashboard interativo no Excel para análise visual. |
| 😴 **Análise de Sono** | Avaliação da distribuição da qualidade do sono entre os participantes. |
| 📱 **Uso de Smartphone** | Análise de uso excessivo do celular, uso antes de dormir e adoção do modo noturno. |
| 🌍 **Insights por País** | Comparação do comportamento dos participantes em diferentes países. |
| 💡 **Insights de Negócio** | Extração de informações úteis dos dados da pesquisa para estudos e tomada de decisão. |

## <img src="https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/sleep-smartphone-analysis.git
````

### 2️⃣ Acesse o Projeto

```bash
cd sleep-smartphone-analysis
```

### 3️⃣ Abra o Arquivo Excel

Abra:

```bash

```

usando o **Microsoft Excel 2016 ou versão posterior**.
